# M.T ポートフォリオサイト

## ■ 概要
Web運用・ECサイト改善・AI活用を想定したポートフォリオです。

更新作業だけでなく、
課題発見 → 修正 → 再確認の流れを意識し、
実務を想定した制作・改善・運用フローを作成しました。

FAQ作成、CMS更新、UI改善、EC改善、生成AI活用など、
実際の運用業務を想定した内容を中心に構成しています。
## ■ 収録作品
1.GAS業務効率化ツール  
更新業務を想定した自動化処理を作成

2.商品LP改善ページ  
導線・余白・CTA配置を見直したUI改善

3.CMS更新デモ  
ボタン操作でコンテンツ切替できる簡易CMS

4.FAQページ（AI活用）  
ChatGPTで生成 → 修正 → HTML化

5.ECサイト改善デモ  
改善前 / 改善後を比較したUI改善

6.AI回答修正例  
AI生成文章を実運用想定で修正

7.FAQ運用フロー設計  
AI生成 → 人確認 → CMS更新 → 公開の流れを設計
